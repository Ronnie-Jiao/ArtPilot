# 灵绘项目 Wiki

灵绘是面向 Adobe Illustrator 的 Windows CEP 扩展和 ExtendScript 工具，提供尺寸调整、图片链接处理与 AI 文件保存优化功能。

## Wiki 导航

- [安装与更新](Installation.md)：系统要求、CEP 安装、更新和独立 JSX 脚本。
- [功能说明](Features.md)：尺寸、缺图修复、互换链接、替换图片和无损压缩的用途与区别。

本目录保存随主仓库版本管理的 Wiki 页面源码。根目录 [README](../README.md) 是 GitHub 访客的项目介绍；这里的页面尚未自动同步到 GitHub 的独立 Wiki 标签页。

## 项目范围

- CEP 面板入口：`CEP/index.html`
- Illustrator 宿主逻辑：`CEP/host/linghui.jsx`
- 可独立运行的脚本：`灵绘.jsx`
- CEP 面板安装：`安装灵绘CEP.cmd`

当前版本号以 `CEP/CSXS/manifest.xml` 为准。
